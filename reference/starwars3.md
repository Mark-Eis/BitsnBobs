# Starwars Dataset with Name and Skin Colour Only

The `name` and `skin_colour` columns from the
[starwars](https://dplyr.tidyverse.org/reference/starwars.html) dataset
in [dplyr](https://dplyr.tidyverse.org/reference/dplyr-package.html).

## Usage

``` r
starwars3
```

## Format

### 

A data frame with 10 rows and 2 columns:

- name:

  Name of the character

- skin_color:

  skin color
