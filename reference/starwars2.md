# Starwars Dataset with Separated First Names and Surnames

[Starwars](https://dplyr.tidyverse.org/reference/starwars.html) dataset
from [dplyr](https://dplyr.tidyverse.org/reference/dplyr-package.html)
with first names and surnames in separate columns.

## Usage

``` r
starwars2
```

## Format

### 

A data frame with 63 rows and 12 columns:

- Firstname:

  Firstname of the character

- Surname:

  Surname of the character

- height:

  height

- mass:

  mass

- height:

  height

- hair_color:

  hair color

- skin_color:

  skin color

- eye_color:

  eye color

- birth_year:

  year of birth

- sex:

  sex

- gender:

  gender

- homeworld:

  homeworld

- species:

  species
