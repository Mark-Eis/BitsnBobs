# Optimise the Value of Lambda for a Box-Cox Transformation

Optimise the value of \\\lambda\\ for a Box-Cox transformation by
minimising skewness and return the optimally transformed data together
with the optimal \\\lambda\\ and corresponding skewness minimum as
attributes.

## Usage

``` r
opt_bc(x, interval = c(-5, 5), tol = 1e-10)
```

## Arguments

- x:

  a `numeric` vector of data to be transformed using optimised values.

- interval:

  a vector containing the end-points of the interval to be searched for
  the minimum.

- tol:

  the desired accuracy.

## Value

A numeric vector the same length as `x` with
[`attributes`](https://rdrr.io/r/base/attributes.html) `lambda` and
`skew` representing the optimal value of \\\lambda\\ and corresponding
skewness minimum respectively.

## Details

Uses the functions
[`boxcox3`](https://mark-eis.github.io/BitsnBobs/reference/boxcox3.md)
to create a Box-Cox transformation function for the given dataset,
[`skewness`](https://mark-eis.github.io/BitsnBobs/reference/skewness.md)
to calculate the skewness of the transformed data and
[`optimise`](https://rdrr.io/r/stats/optimize.html) to search for the
value of \\\lambda\\ that minimises skewness.

## See also

[`skewness`](https://mark-eis.github.io/BitsnBobs/reference/skewness.md)

Other boxcox:
[`boxcox3()`](https://mark-eis.github.io/BitsnBobs/reference/boxcox3.md)
