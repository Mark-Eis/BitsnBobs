# Rat Litter Sizes

Litter sizes in albino rats (n = 815) from Table 7 of King (1924).

## Usage

``` r
litter_sizes
```

## Format

### 

An `integer vector` with length `815`.

- litter_sizes:

  Sizes of albino rat litters.

## Source

King, H.D. (1924). Litter production and the sex ratio in various
strains of rats. *The Anatomical Record*, **27**(5), 337-366.
[](https://doi.org/10.1002/ar.1090270514)[doi:10.1002/ar.1090270514](https://doi.org/10.1002/ar.1090270514)
